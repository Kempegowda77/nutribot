NutriChat AI is an intelligent offline nutrition chatbot developed using a hybrid NLTK and Transformer architecture (DistilBERT/MuRIL). It supports English and Hinglish without relying on cloud APIs. The chatbot follows a five-stage pipeline: (1) NLTK preprocessing (tokenization, POS tagging, lemmatization, stopword removal)
(2) Food Named Entity Recognition (NER) to identify food items
(3) VADER sentiment analysis to detect the user's mood
(4) Transformer-based intent classification and calorie prediction
(5) response generation using trusted USDA and ICMR-NIN nutrition databases. It can answer calorie queries, provide nutrition information, suggest healthy meals, give diet advice, recommend portion sizes, and understand greetings, thanks, and Hinglish queries. The model is trained on USDA, ICMR-NIN, restaurant menu data, and 15,000 Hinglish training samples, covering 8,900+ food items. It achieved 100% intent recognition accuracy on 118 test cases with an average 26 ms CPU inference time. The system is fast, offline, open-source, and well-suited for multilingual nutrition assistance. Current limitations include limited calorie regression data, no long-term conversation memory, and lack of native Hindi (Devanagari) support. Future improvements include voice input, personalized recommendations, multilingual expansion, and better conversational memory.
